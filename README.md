# IE Anagram Rush

A 120-second word game: build industrial engineering terms from a scrambled letter rack.

## Run it
Open `index.html` in any browser. No install or build step.

## Publish with GitHub Pages
1. Upload these files to a public repository.
2. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
3. Your game is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Collecting scores
After each round the game shows a result line with a short code. Have players submit that line (for example through Unstop or a form).
